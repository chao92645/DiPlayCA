# DiPlay — 长安（EADO）定制分支

本分支是 [DiPlay](https://github.com/shihabal3amri/DiPlay) 的**长安 21 款逸动 PLUS（EADO）定制版**，
基于上游 `v0.2.19`（`e06a2502`）派生，分支 `custom-0219`。

安装：包名仍为 `com.shihab.diplay`，**testkey 签名**（盖不过官方签名），安装前需卸载官方版本。

版本号跟随上游（现 `0.2.19`，上游发新版后同步）；各版本的具体改动见 [Releases](https://github.com/chao92645/DiPlayCA/releases)。
安装、连接与构建说明见上游 [README](README.md) 与 [docs](docs/)。
